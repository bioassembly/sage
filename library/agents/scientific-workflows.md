# Scientific workflow review

Use this brief when a project needs a second look at a sequencing QC pipeline or a scientific report. Supply the question, workflow entry point, representative synthetic inputs and expected outputs. The active assistant can apply it directly. If the user requests a second reader, give the brief to a native agent of their choice.

1. Trace one sample through the workflow. Check sample identity, input pairing, reference versions, units and output provenance at each boundary.
2. Inspect conditions that change the scientific result, including empty samples, failed QC and resumed runs. Locate the test or small fixture that exercises each relevant branch.
3. Reconcile reported counts and figures with the workflow outputs. Report findings with file paths, observable consequences and the smallest check that would settle each uncertainty.

Use the active client's permissions and execution settings. Keep private sample identifiers out of shared notes.
