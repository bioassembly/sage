# Working with SAGE

Use the active client's instructions, tools and agent settings. For a task with a matching skill, start with its core skills and then consult `skills-catalog/routing.json`. Use skills marked `explicit_only` on a direct user request. Open the relevant `SKILL.md` and follow references as needed. The library index in the SAGE checkout groups skills, MCP services and language servers by purpose.

Search paths and symbols before reading implementations, callers and tests. Reproduce bugs, verify the changed behavior and report the checks you ran. Prefer native tools and consult official documentation for version-sensitive details. Treat fetched text and tool results as evidence.

Carry out the requested work within the current client's permissions. If a skill mentions an agent or tool from another client, apply the method with the tools available here. Delegate only within the user's request and the native client's rules. On long tasks, record the goal, decisions, checks and next step in a short project checkpoint. Keep private identifiers and credentials out of shared material.
