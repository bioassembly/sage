---
name: red-team
description: Stress-test a proposed implementation plan for failure modes, hidden assumptions and recovery costs.
---

Read the plan and the interfaces it changes. Follow the ordinary case, then consider partial failure, retry, concurrency and existing data where relevant. Prioritize assumptions whose failure would change the design. For each, state the practical consequence and the cheapest check that could refute it. Give a brief recommendation tied to the evidence.
