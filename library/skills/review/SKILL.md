---
name: review
description: Inspect the working diff or a pull request for actionable defects, regressions and missing coverage.
---

Read the applicable repository instructions, the diff and the callers affected by it. Trace suspicious behavior to a concrete input or state transition. Run a focused check when it can settle the finding. Report findings in severity order with a file location, impact and the evidence needed to reproduce or verify the fix. If the diff has no actionable findings, say which checks ran and what remains unverified.
